API reference — Anomaly & density trees¶

Unified anomaly detection: AnomalyModel (tree-based and PCA/NMF reconstruction errors), density estimation, streaming mass scoring, CoDisp, and contextual surprise.

AnomalyModel¶

class AnomalyModel(kind: 'str' = 'eif', max_depth: 'int | None' = None, min_rows: 'int' = 10, contamination: 'float' = 0.05, seed: 'int' = 42, *, extension_level: 'int | None' = None, subsample_size: 'int | None' = None, min_samples_split: 'int | None' = None, alpha: 'float' = 0.0, min_density_gain: 'float' = 0.0, window_size: 'int' = 250, initial_mass: 'float' = 0.0, sample_size: 'int' = 256, eta: 'float' = 0.1, prior_weight: 'float' = 1.0, alphabet_size: 'int' = 256, smoothing_discount: 'float' = 0.5, **params: 'Any')

Unified Tree and Component-Based Anomaly Detector.

Wraps multiple tree-based and component reconstruction anomaly engines: - "eif" or "isolation": Extended Isolation Tree (oblique hyperplanes, mixed types). - "det" or "density": Density Estimation Tree (piecewise constant density, mixed types). - "hst" or "half_space": Streaming Half-Space Tree (mass-based scoring). - "rct" or "random_cut": Random Cut Tree (co-displacement scoring). - "active": Active Anomaly Tree with expert feedback adaptation. - "context": Variable-Order Context Anomaly Tree for discrete sequences. - "pca": Principal Component Analysis subspace reconstruction error. - "nmf": Non-negative Matrix Factorization additive reconstruction error.

Parameters¶

kind : str, default="eif" Anomaly tree engine to use: "eif", "det", "hst", "rct", "active", or "context". max_depth : int, optional Maximum tree depth. min_rows : int, default=10 Minimum leaf samples. contamination : float, default=0.05 Expected proportion of anomalies in the dataset (used to calibrate binary predictions). If the cutoff splits a group of equal scores, the entire group is labeled as inliers. seed : int, default=42 Random seed for stochastic engines (EIF, HST, RCT, Active). extension_level, subsample_size : int, optional EIF hyperplane order and training subsample size. min_samples_split : int, optional DET minimum samples per split. Defaults to twice min_rows. alpha, min_density_gain : float DET density smoothing and minimum gain. window_size : int, default=250 HST stream window size. initial_mass : float, default=0 HST initial node mass. sample_size : int, default=256 RCT sample size. eta, prior_weight : float Active anomaly learning rate and prior leaf weight. alphabet_size : int, default=256 Context tree alphabet size. smoothing_discount : float, default=0.5 Context tree discount for smoothing symbol probabilities.
