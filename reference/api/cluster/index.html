API reference — Clustering trees¶

Tree-based clustering and mixed-type search: TrieKNN, PCT (CLUS), CLTree, HDBSCAN Condensed Tree, and Unsupervised Random Forest (URF).

ClusterTree¶

class ClusterTree(kind: str = 'pct', n_clusters: int | None = None, max_depth: int = 6, min_rows: int = 5, metric: str = 'euclidean', seed: int = 42, *, min_samples_split: int | None = None, min_variance_reduction: float = 0.0001, target_weights: collections.abc.Sequence[float] | None = None, min_density: float = 0.6, min_samples: int | None = None, cluster_selection_epsilon: float = 0.0, max_cluster_size: int | None = None, cluster_selection_method: str = 'eom', allow_single_cluster: bool = False, n_trees: int = 50, max_features: int | None = None, linkage: str = 'average', **params: Any)

Unified Tree-Based Clustering Model.

Wraps divisive and density-based tree clustering engines under a consistent API: - "pct" or "predictive": Predictive Clustering Trees (unsupervised or multi-target supervised, rules). - "cltree" or "density": CLTree (density-based spatial clustering tree with bounding boxes). - "hdbscan" or "hierarchical": HDBSCAN mutual reachability MST hierarchy. - "urf" or "proximity": Unsupervised Random Forest proximity-based clustering.

Parameters¶

kind : str, default="pct" Clustering engine: "pct", "cltree", "hdbscan", or "urf". n_clusters : int, optional Target cluster count (required for URF, auto-detected in HDBSCAN / CLTree). max_depth : int, default=6 Maximum tree depth for divisive clustering trees. min_rows : int, default=5 Minimum leaf samples / cluster size. metric : str, default="euclidean" Distance metric (for HDBSCAN: "euclidean", "manhattan", "chebyshev"). seed : int, default=42 Random seed for stochastic clustering algorithms (URF). min_samples_split : int, optional PCT minimum samples per split. Defaults to twice min_rows. min_variance_reduction : float, default=1e-4 PCT minimum reduction in target variance. target_weights : sequence of float, optional Per-target weights for PCT. min_density : float, default=0.6 CLTree minimum cluster density. min_samples : int, optional HDBSCAN neighbor count for core distances. Defaults to min_rows. cluster_selection_epsilon : float, default=0 HDBSCAN distance threshold for merging clusters. max_cluster_size : int, optional HDBSCAN upper limit on cluster size. cluster_selection_method : str, default="eom" HDBSCAN cluster selection method, "eom" or "leaf". allow_single_cluster : bool, default=False Allow HDBSCAN to select a single cluster. n_trees : int, default=50 Number of trees in the URF proximity forest. max_features : int, optional Number of URF features to consider per split. linkage : str, default="average" URF linkage method, "average", "single", or "complete".
