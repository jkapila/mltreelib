# API reference — Visualization

`mltreelib.plots` — the chart layer. Every chart function takes `ax=None` and returns the `Axes`; compose them into figures as you like. The core library never imports matplotlib — this layer is opt-in via the `[plotting]` extra. **Every plot on this site is click-to-zoom** (standard `medium-zoom`).

## Model diagram

```
m.to_dot()          # Graphviz DOT, left-to-right layout
```

Renders to SVG/PNG with `dot -Tsvg`, or in Python with the `pygraphviz` extra:

```
print(m.to_dot())               # text
m.to_dot("tree.svg")            # file: dot -Tsvg
m.view()                        # Graphviz image window (needs pygraphviz)
```

Real diagram (airfoil fit at depth 3, written by the [visualization example](<https://jkapila.github.io/mltreelib/examples/visualization/index.md>)):

*every internal node tests one numeric threshold; the branch labels are its direction; diamonds are leaves carrying the fitted value + the sample support (`n=`, plus `events=` for classifiers).*
