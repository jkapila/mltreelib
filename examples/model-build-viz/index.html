Model build & Tree Visualization¶

How to build a model, read its output, draw it, and steer it with constraints and regularization. Scripts: examples/model_viz_demo.py, examples/constraints_demo.py, examples/weights_regularization.py.

Draw it (to_svg)¶

model.to_svg() returns a self-contained SVG — one box per node (split condition, n, deviance or fitted value), edges labeled with < t / >= t. Write it to a file or inline it in a notebook.

Monotone constraints¶

monotone=[+1, 0, -1, …] per column pins the direction of the response — enforced at split choice and in leaf coefficients (linear leaves carry effects in their coefficients).

model = ModelTree(monotone=[1, 0])

unconstrained        predictions non-decreasing along x0: False
monotone +1 on x0    predictions non-decreasing along x0: True

Interaction groups¶

interaction_groups=[[0, 1], [2]] — every root-to-leaf path may split only columns of one group (LightGBM-style interaction constraints). Verify with split_paths():

unconstrained        paths mixing groups: 2
groups [[0,1],[2]]   paths mixing groups: 0

Both constraint types are validated against reference implementations (R gbm's var.monotone, LightGBM's interaction_constraints) in examples/constraints_check.py.

Row weights & regularization¶

fit(x, y, w) accepts row weights (0 = row ignored). Upweighting the top of x0 moves the fitted leaf values where the weight is:

unweighted leaf means: [1.25, 2.26, 3.27, 4.26]
weighted leaf means:   [1.25, 2.26, 3.47, 4.43]

l1/l2 penalize leaf coefficients. With two collinear predictors the three personalities are textbook:

ridge  (l2)  leaf coefficients: [1.472, 1.469]   # shares the effect
lasso  (l1)  leaf coefficients: [2.8, 0.0]       # picks one
elastic      leaf coefficients: [0.933, 0.933]   # in between

Relevance screening¶

min_relevance screens columns before the split search — cheap insurance on wide data (drop pure noise):

min_relevance=0.05 -> splits use columns ['x0', 'x1'] (noise column 2 gone: True)
