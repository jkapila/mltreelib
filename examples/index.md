# Example library

Use a [modeling pathway](<https://jkapila.github.io/mltreelib/guides/index.md>) for a complete study on real data. Come here when you have a specific question about one part of the workflow.

| If you want to… | Use this example |
| --- | --- |
| Check how a tree routes missing predictors | [Missing routing](<https://jkapila.github.io/mltreelib/examples/missing-routing/index.md>) |
| Supply a numeric representation to another estimator | [Optional categorical encoders](<https://jkapila.github.io/mltreelib/examples/categorical-encoders/index.md>) |
| Build past-only features and a time split | [Forecasting](<https://jkapila.github.io/mltreelib/examples/timeseries-forecasting/index.md>) |
| Adjust tree depth and leaf support | [Growth knobs](<https://jkapila.github.io/mltreelib/examples/knob-tour/index.md>) |
| Compare local model predictions and rules | [Model building](<https://jkapila.github.io/mltreelib/examples/model-building/index.md>) and [rules and neighbors](<https://jkapila.github.io/mltreelib/examples/rules-summary-knn/index.md>) |
| Review a prediction or export a tree | [Inspection](<https://jkapila.github.io/mltreelib/examples/inspection/index.md>) and the [visualization catalog](<https://jkapila.github.io/mltreelib/guides/visualization/index.md>) |
| Check a monotone or interaction constraint | [Constraints](<https://jkapila.github.io/mltreelib/examples/constraints/index.md>) |
| Update an existing model or routing structure | [Hierarchical retraining](<https://jkapila.github.io/mltreelib/examples/hierarchical-retrain/index.md>) |
| Work with censored values or follow-up | [Tobit regression](<https://jkapila.github.io/mltreelib/examples/tobit-regression/index.md>) and [survival mechanics](<https://jkapila.github.io/mltreelib/examples/survival-trees/index.md>) |
| Check recovery of a known intervention effect | [Causal simulation](<https://jkapila.github.io/mltreelib/examples/causal-uplift/index.md>) and [honesty and weights](<https://jkapila.github.io/mltreelib/examples/honesty-weights/index.md>) |
| Compare two settings for segmentation or triage | [Clustering diagnostics](<https://jkapila.github.io/mltreelib/examples/clustering-comparison/index.md>) and [anomaly review budgets](<https://jkapila.github.io/mltreelib/examples/anomaly-comparison/index.md>) |
| Choose an evaluation plot or metric | [Metrics and plots](<https://jkapila.github.io/mltreelib/examples/metrics-plots/index.md>) |

The navigation groups the examples by workflow stage. Synthetic examples serve as controlled experiments when you need known truth. The dataset guides use observed outcomes and independent review rows.
