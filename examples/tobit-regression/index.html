Tobit & Censored Regression Trees¶

When response variables have a natural boundary — such as insurance claims, consumer expenditures, or labor supply hours bounded at zero — linear regression estimates suffer from attenuation bias: the estimated slopes flatten toward zero because unobserved negative latent desires are clipped to the boundary.

ModelTree provides native Tobit regression leaves (leaf_family="tobit") fitted via iterative reweighted least squares (IRLS / EM) inside tree partitions.

Script: - examples/tobit_benchmark.py (python3 examples/tobit_benchmark.py)

1. The Tobit Model Formulation¶

The standard formulation assumes a latent continuous variable \(y^*_i\): $\(y^*_i = x_i' \beta + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)\)$

Observed outcomes are left-censored at threshold \(c\) (default \(c = 0\)): $\(y_i = \begin{cases} y^*_i & \text{if } y^*_i > c \\ c & \text{if } y^*_i \le c \end{cases}\)$

The log-likelihood consists of discrete probability mass at \(c\) and continuous Gaussian density for uncensored observations: $\(\ln L = \sum_{y_i = c} \ln \left[ 1 - \Phi\left(\frac{x_i' \beta - c}{\sigma}\right) \right] + \sum_{y_i > c} \left[ -\frac{1}{2}\ln(2\pi\sigma^2) - \frac{(y_i - x_i' \beta)^2}{2\sigma^2} \right]\)$

2. ModelTree Tobit Usage¶

from mltreelib import ModelTree

# Fit a piece-wise linear Tobit tree
tree = ModelTree(
    max_depth=2,
    min_rows=30,
    leaf="linear",
    leaf_family="tobit",
    l2=1e-3,
    tobit_threshold=0.0,
)
tree.fit(X, y)

# Predict latent expected response
predictions = tree.predict(X_test)

3. Econometric Benchmark: Mroz (1987)¶

On the classic Mroz female labor supply dataset (datasets/external/mroz.csv): - 43.2% of women in the survey reported 0 hours worked. - OLS attenuates the disincentive effect of infant children (kidslt6), giving \(-403.61\) hours. - Tobit tree leaf model recovers the unattenuated latent marginal disincentive of \(-436.19\) hours.
