Suite 11: Component Analysis, Matrix Factorizations & R-Aligned Rotations¶

Benchmark pure-Rust linear decompositions, covariance whitening transforms, R-aligned factor rotations, Non-Negative Matrix Factorization (NMF) solvers, and out-of-subspace anomaly detection in mltreelib-core.

Run suite from repository root after building release extension:

uv run python examples/suites/component_benchmarks.py

1. Architectural Architecture & Task Facades¶

In tabular feature spaces, correlated variables represent underlying latent traits (chemical profiles, macroeconomic cycles, patient health statuses). Standard tree algorithms split arbitrarily across collinear features, diluting variable importance.

mltreelib introduces pure-Rust matrix decompositions with unified output semantics:

2. Mathematical Formulations¶

1. Principal Component Analysis & Truncated SVD¶

Given centered data \(X_c = X - \mathbf{1}\mu^T \in \mathbb{R}^{N \times P}\), thin SVD yields: $\(X_c = U \Sigma V^T\)$ - Projected latent scores: \(Z = X_c V_k \in \mathbb{R}^{N \times k}\). - Unrotated factor loading matrix: \(L = V_k \Sigma_k^{1/2} \in \mathbb{R}^{P \times k}\).

2. Covariance Whitening: PCA vs. ZCA¶

Transforms covariates into decorrelated representations with identity sample covariance \(\text{Cov}(Z) = I\):

  • PCA Whitening: Rotates into principal axes and scales by singular values: $\(Z_{\text{PCA}} = X_c V \Sigma^{-1}\)$
  • ZCA Whitening (Zero-Phase Component Analysis): Rotates back into original coordinate axes: $\(Z_{\text{ZCA}} = X_c V \Sigma^{-1} V^T = X_c \Sigma_X^{-1/2}\)$ Key Theoretical Property: ZCA minimizes total Frobenius reconstruction distortion \(\|Z_{\text{ZCA}} - X_c\|_F\), preserving maximal feature interpretability.

3. The Orthomax & Promax Factor Rotation Family¶

Unrotated PCA loadings are dense. Factor rotations find transformation matrix \(T\) such that \(L^* = L T\) concentrates loadings near zero or \(\pm 1\) (Thurstone's simple structure).

  • Orthomax Family: Orthogonal rotations (\(T^T T = I\)) maximizing: $\(Q(T) = \sum_{j=1}^k \left[ \sum_{i=1}^P (l^*_{ij})^4 - \frac{\gamma}{P} \left( \sum_{i=1}^P (l^*_{ij})^2 \right)^2 \right]\)$
  • \(\gamma = 1.0\): Varimax (aligned with R stats::varimax). Maximizes loading variance within factors.
  • \(\gamma = 0.0\): Quartimax. Maximizes loading variance across rows.
  • \(\gamma = k/2\): Equamax. Balances row and column simplification.
  • \(\gamma = \frac{P(k-1)}{P+k-2}\): Parsimax. Penalizes complex factor assignments.

  • \(\gamma = \frac{k}{2P}\): Biquartimax.

  • Promax Rotation: Oblique rotation (\(T^T T \ne I\)) allowing correlated latent factors:

  • Compute orthogonal Varimax loadings \(L_{\text{varimax}}\).
  • Construct target simple-structure matrix \(B\) by element-wise exponentiation: $\(B = (L_{\text{varimax}})^{\circ m} \oslash |L_{\text{varimax}}|, \quad m = 4\)$
  • Solve Procrustes least-squares problem: \(T = (L^T L)^{-1} L^T B\), followed by column normalization.

4. Non-Negative Matrix Factorization (NMF)¶

Approximates non-negative data \(X \ge 0\) as \(X \approx W H\) where \(W \in \mathbb{R}^{N \times k}_{\ge 0}\) (basis) and \(H \in \mathbb{R}^{k \times P}_{\ge 0}\) (encodings): $\(\min_{W \ge 0, \, H \ge 0} \frac{1}{2} \|X - WH\|_F^2 + \lambda_1 \|H\|_1 + \frac{\lambda_2}{2} \|H\|_F^2\)$

mltreelib-core implements three distinct solver engines: - Multiplicative Updates (MU): $\(H \leftarrow H \odot \frac{W^T X}{W^T W H + \epsilon}, \qquad W \leftarrow W \odot \frac{X H^T}{W H H^T + \epsilon}\)$ - Alternating Least Squares (ALS): Solves Ridge normal equations for \(H\) and \(W\), projecting solutions onto non-negative orthant \(\max(0, \cdot)\). - Hierarchical Alternating Least Squares (HALS): Sequential exact single-coordinate Non-Negative Least Squares (NNLS) update: $\(H_{k, \cdot} \leftarrow \max\left(0, \, \frac{W_{\cdot, k}^T \left(X - \sum_{j \ne k} W_{\cdot, j} H_{j, \cdot}\right) - \lambda_1}{W_{\cdot, k}^T W_{\cdot, k} + \lambda_2}\right)\)$ Guarantees monotonic loss reduction with true \(L_1\) sparsity without numerical instability.

3. Empirical Benchmark on Real Data¶

We evaluate the full component analysis suite on the Wine Quality dataset (1,000 samples, 12 continuous chemical features).

from mltreelib import ComponentModel, AnomalyModel, load_dataset

# Ingest Wine Quality benchmark
data = load_dataset("wine_quality")
X = [[data["columns"][c][i] for c in data["columns"].keys() if c != "quality"] for i in range(1000)]

4. Subspace Reconstruction Anomaly Detection¶

Out-of-subspace anomalies project poorly onto low-rank basis components, producing large reconstruction residuals: $\(\mathcal{L}_{\text{anom}}(x) = \|x - \hat{x}\|_2^2 = \|x - W h(x)\|_2^2\)$

# Detect anomalies via subspace reconstruction error
detector = AnomalyModel(method="pca", n_components=3)
detector.fit(X)

inlier_loss = detector.score_samples([X[0]])[0]
outlier_point = list(X[0])
outlier_point[0] += 50.0  # Synthetic feature injection
outlier_loss = detector.score_samples([outlier_point])[0]

print(f"Normal Inlier Loss:  {inlier_loss:.4f}")
print(f"Outlier Spike Loss:  {outlier_loss:.4f}")
print(f"Separation Ratio:    {outlier_loss / inlier_loss:.1f}x")

4. Operational Limitations & Failure Modes¶

  1. Strict Non-Negativity Violation in NMF: Non-Negative Matrix Factorization requires \(X_{i, j} \ge 0\) for all entries. Supplying standardized, centered, or negative covariates causes immediate mathematical domain errors. Shift or scale features to the interval \([0, 1]\) before fitting NMF.
  2. Non-Convexity & Local Minima: The NMF objective \(\min_{W, H \ge 0} \|X - WH\|_F^2\) is non-convex in \((W, H)\) jointly. Convergence to a global minimum is not guaranteed. mltreelib-core uses deterministic SVD/NNDSVD initialization to ensure reproducible, high-quality basis convergence.
  3. Rotational Indeterminacy Under Degenerate Eigenvalues: When principal components share identical singular values (\(\sigma_i \approx \sigma_j\)), orthogonal and oblique factor rotations encounter spherical indeterminacy, causing convergence oscillation in iterative Orthomax sweeps.
  4. Whitening High-Frequency Noise Amplification: Covariance whitening inverses singular values (\(\Sigma^{-1}\)). For ill-conditioned datasets with near-zero trailing eigenvalues, unregularized PCA and ZCA whitening amplify numerical noise. Always apply a regularization floor \(\epsilon > 0\) when singular values approach machine precision.
